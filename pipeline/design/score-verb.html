DECISIONS

DT-1 · recommend A, GROW. Checks stay one always-visible mono line (they gate the commit); a failing segment turns rust. M4's bar map enters as a collapsed BARS ▸ disclosure (the TUNE idiom). Beat: B (hides rejected ops), C (hides the gates). Cost: dock jumps ≈ +80 px on plan-ready; at 1366×768 the page scrolls.
DT-2 · recommend A, C. Free, mnemonic. Beat: O (reads as zero), P (label SCORE, key P), no key. Cost: a later COMPARE verb would want C.
DT-3 · chip BASE · WHOLE SCORE, sky, like SPLIT's BASE · WHOLE LAYER; the planned-against version sits in the checks and stale lines. Beat: WHOLE SONG (same as EXPORT), BASE v2 · WHOLE SCORE (changes every render). M2: a picked section becomes a sky suffix, no waveform wash.
DT-4 · hues. Errors, refusals, TRUNCATED, failed checks: rust. Version badge and current row: lilac (a truncated v3 adds a small rust tag). Chip sky. APPLY & RENDER is the only acid fill; PLAN is an acid outline sibling, always present, so the two-step shape never moves. Beat: PLAN filled until a plan exists (the fill would jump); hairline PLAN (it starts a GPU job). Row tags are text-low: rust on every REHARMONIZE would be alarm fatigue.
DT-5 · dimmed old plan. Opacity .4, dashed hairline (dashed = waiting), a label, unpressable, APPLY off. Beat: hide at once (dock collapses then regrows), leave lit (looks applicable), strike-through (reads as rejected).
Shader. Planning and rendering lines wear it once the GPU works; queued stays dashed. The planner is an LM working, like Quick Start in DESIGN's list; the F-021 PR adds "planning". Rendering follows DESIGN's YuE2 rule (stage share, no veil), correcting scope.md. Beat: plain text (3-10 s looks hung). DESIGN.md (own commit) gets: tab + key, chip, SCORE body, consequence grammar, shader list.
