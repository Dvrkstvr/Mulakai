SP-7 · read the German lyrics: which models write usable first takes?

Four local models each wrote the lyrics for the same song idea (same prompt, same sections, one run, nothing picked or fixed). For every request the four sets are shuffled and labelled X1..X4, so you do not know which model wrote which until you press reveal. Mark each set usable (you would press CREATE SONG on it and edit from there: natural German, lines that sing, rhymes that do not feel forced) or not usable, with an optional note. Pass bar for a model: 5 of 6 German sets usable. The names are hidden in the page's data too; reveal after you have voted.
